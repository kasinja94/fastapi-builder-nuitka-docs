# FastAPI Builder — Documentation

This repository contains the documentation for [fastapi-builder-nuitka](https://pypi.org/project/fastapi-builder-nuitka/), a tool for compiling, packaging, and securing FastAPI applications using Nuitka.

## Local Preview

Requirements: Python 3.11 or later.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-docs.txt
mkdocs serve
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000) in a browser.
